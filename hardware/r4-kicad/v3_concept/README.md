# v3 concept drawings: coil tab, battery placement, connection, service access

Generated by `tools/battery_drawings.py`, which uses the geometry from
`tools/layout_study.py`. That geometry comes from the R3 assembly model, the R4
KiCad outline, the CAL1020 size-S orthotic outline and the sensor layer. Plans
are viewed from above, toe up. They are concepts for review, not a board
layout.

## Key choices

- **No cell stacked on components.** The pack lies flat in a die-cut pocket (+0.5 mm) in the electronics layer, so the bay thickness is set by the cell alone.
- **Battery connection.**
  - Prototype: a JST ACH 2-pin header (1.2 mm pitch, 1.4 mm high), with Master Instruments crimping the plug onto the pack's AWG30 leads.
  - Production: a custom pack with a flex tail to a Hirose BM28 (0.6 mm stacked).
- **Strain relief.** Leads leave the PCM end, run in a service loop outside the board edge and the coil keep-out, and are staked to the electronics layer, never to the cell.
- **Connector position.** The header sits on the board's free outer edge; the castellated edges carry the sensor tails.
- **Service face down.** Components, the connector and the test points face the bottom layer. A hatch there (lid on re-closable adhesive) gives access to the pack, the connector and the test points, so the foot-side top cover stays continuous.
- **Service strip.** All test points are grouped beside the connector (today they are spread over the board), plus a new **VBAT** test point on the pack side of F1.
